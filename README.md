# Maghrebia Insurance Management System

Welcome to the **Maghrebia** project — a complete and modular insurance management system. This project supports a wide range of functionalities for managing insurance products, contracts, claims, payments, and more, with roles for **Client**, **Insurance Agent**, and **Administrator**.

## 🚀 Key Features

- Authentication and role-based access control
- Insurance product and agency management
- Contract subscription and quote requests
- Claims and complaints declaration and tracking
- Credit request and insurance payment
- Statistical dashboard for performance monitoring
- Clear separation of responsibilities per user role

## 🧰 Technologies Used

- **Backend**: Java / Spring Boot
- **Frontend**: Angular or React
- **Database**: MySQL or PostgreSQL
- **Other Tools**: Docker, Maven, Postman
- **UML Diagrams**: Use Case and Class diagrams
